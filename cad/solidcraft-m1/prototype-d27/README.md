# D2.7 · Плоскі опори Mac і змінний тримач живлення

Цифровий прототип для [холодної примірки](FIT-FIRST.md) на базі D2.6. [Переглядач D2.7](https://univera-llc.github.io/m1-enclosure/) · [архів D2.6](https://univera-llc.github.io/m1-enclosure/d2.6/).

У D2.6 буртики Ø3,80 мм заходили в отвори втулок Mac (Ø4,40 мм за SOURCE) і обмежували рух до затягування гвинтів. D2.7 прибирає обидва буртики: плата спирається на ті самі кільця Ø7,00 мм на `Z=14,00`. Осі гвинтів, пілоти Ø2,60 мм і дві задні опори від перекидання збережені. Після зняття буртиків портову панель використовують для звірки положення плати перед затягуванням гвинтів. Перевірте кожен порт без вигину панелі.

`01` — один знімний тримач із вузькою основою, двома пазами під край кожної плати та одним верхнім обмежувачем на плату. За CAD об’єм зменшився з 3 111 до 2 067 мм³. USB‑C зберігає упори під метал гнізда, що потребують примірки на фактичному корпусі роз’єму. Вушка та висота пайки залишаються припущенням. Тримач не має гвинтів до корпуса. Стяжка в тунелі призначена для ізольованих дротів.

Для іншого модуля той самий інтерфейс: desk mm, `+Y` назад, `+Z` вгору; штифти Ø4,80 мм, висота 2,55 мм над підлогою `Z=8,40`; центри `(−79,10; −9,29)` і `(−79,10; 35,71)` з кроком 45 мм. Повний круг штифта має висоту 0,20 мм, решта профілю підтримує горизонтальне заведення на дно. Поточна відповідна пара в `01` — круглий Ø5,40 мм і поздовжній паз `5,40 × 6,80 мм`. З іншим тримачем слід заново перевірити утримання з кришкою, дроти, вентиляційні зони та навантаження від штекера.

Відтворення з [перевіреної збірки D2.6](../../../docs/CAD-BUILD.md) під `build/`:

```powershell
uv run --locked python -B cad/solidcraft-m1/prototype-d27/build_d27.py --baseline build/d26-clean-source-2 --output build/d27-fit-new
```

Вихід: SolidCraft, два STEP, цифровий звіт посадки, нарізання змінених STL і два комплекти. `02/05/07` перевикористовують байти D2.6 після геометричної звірки. Відкриті фізична посадка, міцність, силовий стенд, охолодження та RF.
