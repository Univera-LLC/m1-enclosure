# Sources and rights

The enclosure, rear panel, lid, module holder, front blank and fit samples are project designs. The viewer also contains reference geometry from other creators. The origin of each matters when copying, modifying or distributing a model or an image.

| Material | Origin and use |
| --- | --- |
| Mac logic board, heatsink and antenna references | **Quinn Nelson / SnazzyLabs**, [*Shrink the M1 Mac mini!* · Printables 139893](https://www.printables.com/model/139893-shrink-the-m1-mac-mini). The source records **Creative Commons Attribution–NonCommercial (CC BY-NC)** without a version number. Preserve the attribution and the noncommercial terms on reuse of the source, its derivatives and images that incorporate them. The D2.6 board reference starts from component 20, retains its coordinate basis and revises visual details of the heatsink and ports. It is not a measured production model. |
| Accessory references | SnazzyLabs components 11, 13 and 14 were shape or scale references for the antennas; component 12 provided the basis for the speaker body. The accessory atlas shows the individual parts, separate from the D2.6 cold-fit assembly. |
| Images in this README | Compositions of D2.6 CAD renders already embedded in the [public viewer](https://dvaderfun.github.io/mac-mini-m1-case-prototype/): `overview` for the cover, `inside` and `panel-back` for the detail sheet. The new compositions crop and label these renders. Views containing the board retain the SnazzyLabs attribution above. None of these images is a photograph of a physically accepted D2.6 case. |
| Owner and Apple reference images | The project used owner-supplied photographs for visual registration and [Apple’s Mac mini reference](https://support.apple.com/en-us/102852) for comparison. Private photographs are not distributed here. Mac mini is an Apple product; this is an independent enclosure project. |
| Connectors and power modules | USB-IF, HDMI, IEC/FCC and connector manufacturers’ drawings informed interface envelopes. The CMTPD (483069554) and Mini-560 (398197737) envelopes refer to Radio Construct / Rozetka products. These are project models with stated assumptions. The separate comparison PCB v1 is credited to **Yulii Maievskyi**; its representation does not grant rights to redistribute its underlying project. |
